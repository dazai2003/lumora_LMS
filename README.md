# Lumora LMS - Learning Analytics & Course Management Platform

AI-Powered Student Engagement and Learning Analytics Platform for Large-Scale Online Education.

## Quick Start Guide

For full instructions on setting up and running the application on `localhost`, please see the [STARTUP_GUIDE.md](file:///d:/BSc%20SE/Final%20Project/lumora_LMS/STARTUP_GUIDE.md).

### Summary

1. **Backend**:
   ```bash
   cd backend
   .\venv\Scripts\activate
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```

2. **Frontend**:
   ```bash
   cd frontend
   npm run dev
   ```

3. **Login Accounts**:
   - **Student**: `student1@fdp.com` / `student123`
   - **Teacher**: `teacher@fdp.com` / `teacher123`
   - **Admin**: `admin@fdp.com` / `admin123`
